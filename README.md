# 🐦 Red Social

## 📖 Descripción

Aplicación web desarrollada con JavaScript que simula una versión simplificada de la red social Twitter.

Este proyecto fue realizado como parte del curso **JavaScript para DOM** de Digital House y está desarrollado utilizando HTML, CSS y JavaScript.

## 🚀 ¿Cómo ejecutar el proyecto?

1. Clonar el repositorio:

```bash
git clone https://github.com/Nicolas-1990/Red-Social-DH
```

2. Abrir el proyecto en Visual Studio Code u otro editor.

3. Ejecutar **Open with Live Server** sobre el archivo `index.html`.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## ▶️ Requisitos

- Git instalado.
- Visual Studio Code.
- Extensión **Live Server**.
